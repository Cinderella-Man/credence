# Rules requiring proposed assumptions (stage 3 — mapping)

One `## <base>` row per rejected rule that stage 3 found could be resurrected, but
only once a proposed assumption is landed. Many rows may point at one catalog entry
(`- Assumption:`) in `proposed_assumptions.md`. Each row carries this rule's own
`- Narrowing:` (the shrink-first move) and `- Property test:` sketch — the
per-rule work that fitting the promise requires.

When a human lands the assumption, **delete the rows here that name it** (see the
landing step in `proposed_assumptions.md`) and re-feed those rule bases through
stage 1.
